= Tarantool nats connector

== Установка

Перед установкой модуля необходимо установить git, tarantool и tt.

[source]
----
tt rocks install https://raw.githubusercontent.com/muxa-xoma/tarantool-nats-connector/refs/tags/v0.1.0/nats-v0.1.0-1.rockspec
----

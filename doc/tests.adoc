= Окружения

== Окружение разработчика

=== Start

[source,bash]
----
docker compose --profile dev up -d
sleep 1
docker exec -it tarantool-dev console
----

=== Stop

[source,bash]
----
docker compose --profile dev down -v --rmi local
----
